# Support

For questions, bug reports, or feature requests related to H3 (Hermes Harness Hooks):

- **GitHub Issues:** [get-h3/h3/issues](https://github.com/get-h3/h3/issues)
- **Discussions:** [get-h3/h3/discussions](https://github.com/get-h3/h3/discussions)
- **SDK-specific issues:**
  - Go: [get-h3/sdk-go/issues](https://github.com/get-h3/sdk-go/issues)
  - Python: [get-h3/sdk-python/issues](https://github.com/get-h3/sdk-python/issues)
  - TypeScript: [get-h3/sdk-typescript/issues](https://github.com/get-h3/sdk-typescript/issues)
- **Shim / CLI issues:** [get-h3/shim/issues](https://github.com/get-h3/shim/issues)
- **Protocol spec issues:** [get-h3/protocol/issues](https://github.com/get-h3/protocol/issues)
