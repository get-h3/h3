# Governance

## Project Governance

H3 (Hermes Harness Hooks) is governed by the maintainers of the get-h3 GitHub organization.

## Decision Making

- Technical decisions are made via consensus among active maintainers
- Protocol changes require a spec update and at least one SDK implementation
- Breaking changes follow the deprecation policy (see specs/24-Compatibility-Matrix.md)

## Maintainer Responsibilities

- Review and merge pull requests
- Ensure test battery passes (43/43 compliance)
- Maintain cross-repo compatibility across all SDKs
- Keep documentation and specs current
